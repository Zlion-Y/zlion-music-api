它是什么

不中转音频流的音乐直链代理：只做「搜索 / 取播放直链 / 歌词 / 封面」，返回各平台 CDN 的原始地址， 浏览器直接去拉。音源脚本（洛雪自定义源格式）在服务端跑，可在管理页上传或填远程地址自动更新。 未配置脚本时只能解析网易免费曲，VIP / 版权受限曲目需要音源脚本。
